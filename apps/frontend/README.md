# Ayuda Colombia Frontend

Interfaz pública React, TypeScript y MapLibre orientada primero a dispositivos móviles.

## Desarrollo

```bash
npm install
npm run dev
```

Pruebas y compilación:

```bash
npm test
npm run build
```

Los datos remotos se administran con TanStack Query. El mapa se carga de forma diferida y
siempre ofrece una alternativa textual accesible.

Consulta [la arquitectura](../../docs/04_EXPLANATION/architecture.md) y el
[contrato generado de la API](../../docs/03_REFERENCE/openapi.json).
